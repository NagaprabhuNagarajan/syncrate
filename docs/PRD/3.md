# Module 1

# Dashboard

## Purpose

The Dashboard is the landing page after successful authentication.

It provides every user with real-time business insights based on their role and permissions.

The dashboard should eliminate the need to navigate across multiple modules to understand business performance.

---

## Objectives

The Dashboard must answer these questions immediately.

Owner

• How much did I sell today?

• How much profit did I make?

• Which invoices are pending?

• Which customers haven't paid?

• Which products are running out of stock?

• What requires my attention?

---

Accountant

• Pending collections

• Pending supplier payments

• GST summary

• Today's invoices

---

Sales Executive

• Today's sales

• Assigned quotations

• Follow-up customers

---

Warehouse Manager

• Low stock

• Stock transfers

• Damaged inventory

---

## User Stories

Story DSH-001

As an Owner

I want to view today's sales

So that I know business performance.

---

Story DSH-002

As an Accountant

I want overdue invoices

So that collections can begin.

---

Story DSH-003

As Warehouse Manager

I want low stock alerts

So that products are reordered.

---

## Business Rules

Dashboard only displays information the logged-in user has permission to access.

Revenue must exclude cancelled invoices.

Profit excludes draft invoices.

Deleted invoices never appear.

Soft-deleted records remain excluded.

---

## Acceptance Criteria

✓ Dashboard loads within 2 seconds

✓ Widgets load independently

✓ Widgets retry automatically on failure

✓ Empty states displayed correctly

✓ Mobile responsive

✓ Supports dark mode

# Module 2

# Organization Management

## Purpose

Every tenant represents one organization.

Organizations are isolated.

Data must never leak between organizations.

---

## Features

Create Organization

Edit Organization

Deactivate Organization

Organization Logo

GST Number

PAN

Address

Business Type

Time Zone

Currency

Financial Year

---

## Business Rules

Organization Name must be unique.

GST validation mandatory for GST-enabled businesses.

Organization deletion is never allowed.

Only Super Admin can deactivate.

---

## Acceptance Criteria

Organization creation completes in less than 10 seconds.
