Syncrate is an AI-powered Connected Business Operating System (SaaS) for Small and Medium Enterprises. It is NOT just invoicing software — it is a full business operating network.

**Why:** The core competitive differentiator is the Connected Business Network (CBN): instead of exchanging PDF invoices via WhatsApp/email, businesses exchange structured digital transactions that automatically synchronize inventory, ledgers, and reports on both sides — eliminating duplicate data entry.

**How to apply:** Every feature built must consider the CBN angle and multi-tenant isolation. Business logic should align with the defined product philosophy: every feature must Save Time, Reduce Manual Work, Increase Revenue, Reduce Errors, Improve Collaboration, or Provide Actionable Insights.

**Core Modules (in priority order per roadmap):**
1. Identity & Organization (Sprint 1)
2. Customer & Supplier Management (Sprint 2)
3. Product, Inventory & Warehouse (Sprint 3)
4. Purchase Management (Sprint 4)
5. Sales, Invoicing & GST (Sprint 5)
6. Payments & Reports (Sprint 6)
7. Connected Business Network (Sprint 7)
8. AI Platform (Sprint 8)
9. Enterprise Features — Workflows, Approvals, Audit Center, API (Sprint 9)
10. Marketplace (Sprint 10)

**Current state:** No application code exists yet. Only documentation. The repo has only a docs folder, LOGO.png, and ICON.png. Phase 0 (foundation) has not started.

**Target market:** SMEs — Retail, Wholesale, Distribution, Manufacturing, Trading. Initially India (GST-compliant), then international.

**Subscription tiers:** Free → Starter → Professional → Enterprise. Paid plans include CBN; Free does not. AI runs on a credit model.
